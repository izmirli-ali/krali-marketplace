# Security

This repository is a thin public distribution package. It must never contain:

- application or server source code;
- database files or research records;
- owner credentials, API keys, tokens, cookies, or environment files;
- browser history, chat history, DMs, or private social-media data.

The live service is centrally controlled. Removing this repository does not disable already installed clients; the owner-only server pause control is the authoritative shutdown mechanism.
